## 一、四处批评的核验结果

### 1. `oracle_truth` 不是策略上界 —— **批评成立，我的表述错了**

代码事实（`analysis/stage2_proxy.py:235`）：权重由 `align_vec(priors, T_lab)` 在**已标注子集的真值核**上计算，
再作用到全部先验核上。而已标注扰动的真值响应本来就是任何主动学习策略可见的信号
（`stage2_proxy.py:227` 里 `T_lab = Y@Y.T` 的已标注块）。因此：

- 它既没有优化最终选样收益，也没有搜索最优权重序列 → **不能称为上界**；
- 它实际上是"用对齐度加权、且不含模型核"的**可部署方法**（与 `align` 的差别只是少了模型核），
  所以"连 oracle 都赢不了"这个论断**不成立**。

**修正后的表述**：在已测试的配置与代理环境中，几种加权方法没有显示出足够吸引人的收益，
因此**暂缓**该方向，但**不能**推出"不存在可赢空间"。

另外 `stage2_proxy.py:208` 的参考核 `ref_kernel` 由**全体真值响应**（含测试扰动）构建，
确实泄漏了测试集的几何结构 → 它只能作为**离线几何诊断**，不能解释为可部署预测器的泛化表现。
**推论**：代理上的增益量级同样不能直接迁移到 GEARS，不只是"排序需降级"。

> 若确实需要一个诚实的上界，应当：在每次决策点直接搜索"最优化最终评估指标"的权重（用测试真值），
> 明确标注为不可部署的诊断上界；而不是用可观测真值算出的对齐权重冒充上界。

### 2. stage4 的 97.5% 不是"学会了感知" —— **批评成立**

代码事实：`stage4_planner_learnability.py:45` 每次只换已标注子集，**测试集 `te` 与八个先验核始终不变**。
于是每个先验的 `align_te` 是常数，40 次抽样只重复 8 个不同的目标值。
"每子集 oracle = 全局最优固定先验"是**任务构造直接决定的**，不能证明真实上下文中适应没有价值。

CV 实现（`stage4:93`）确实是**留一行**（留出"某先验在某子集"这一条记录），
其余同一先验在别的子集上的记录仍在训练集里 → 不是"留一子集"或"留一先验"。

**修正后的表述**：该实验只说明——
**在这个固定的 K562 测试集上，可以从观测子集里识别出哪个先验的对齐度更高（r≈0.87）**。
这与我 stage1 的独立发现（先验质量的**排序**跨子集稳定、相关 0.895）一致，
但它是**单个任务内**的性质，不能外推到"跨上下文适应没有价值"。

同时**删除**"线性探针学不到 → LLM 也学不到"这一推论：线性模型失败不构成一般性不可学习证明，
LLM 还可以使用文本证据。

### 4. 复现偏差的归因过于武断 —— **批评成立，其中 Random 一条我彻底错了**

**(a) Random**：我实测了当前环境（torch 2.14.0+cu130）：

```
fresh torch.Generator(), no manual_seed : [10, 0, 13, 18, ...]
after torch.manual_seed(999)            : [10, 0, 13, 18, ...]   ← 完全相同
after torch.manual_seed(12345)          : [10, 0, 13, 18, ...]   ← 完全相同
CUDA 上同样不变
```

并且**直接比对两个 Random run 的选择集**：run1 与 run2 在**全部 5 轮选的扰动完全相同**
（每轮 100/100 重合，例如 round1 都是 `ACD, ACOT12, ACTR10, ...`）。
→ `RandomSelectionMethod`（`bmdal_reg/bmdal/selection.py:233`）里的生成器**使用固定默认种子**，
`manual_seed` 对它无效。所以：

- **不是"未播种 → 不可复现"**，而是"**固定种子 → 所有 run 共用同一条抽样序列**"；
- run1(0.2825) 与 run2(0.2646) 的差异**全部来自训练种子**（`torch.manual_seed(run)`），不是抽样差异；
- 因此这个 Random 基线实际上只有**一条**选择序列、10 个训练种子，它的"随机性"被严重低估。

**(b) BALD**：我说"梯度特征在新显卡上不稳定"属于**未验证假设**。已核实的是

**(c) pops 核版本**：同样**不成立**——下载时间不同不构成证据；需要文件哈希/原文件比对才能判断，

## 二、新实验：细胞分配到底有没有价值？（stage6 / 6b / 6c）

这是审阅建议的核心问题。我做了三步，前两步都发现**方法学陷阱**，第三步给出公平答案。

**stage6（初步模拟）**：C = 50 细胞/扰动，两阶段（25 或 100）vs 均匀 50 →
可观测特征规则 0.4317 **低于**均匀 0.4406；oracle 仅 +0.0053。

**stage6b（预算扫描）**：在 37.5/62.5/75 等中间预算上，混合策略看似大胜（+0.03~+0.045）——
**但这是离散化假象**：均匀臂只能用测量过的深度（25/50/100），在 37.5 时被迫浪费预算。
且"按增益排序"不等于"按阈值目标排序"，oracle 的构造本身也有问题。

**stage6c（公平比较：等成本 + 连续深度插值 + 逐目标 oracle）**：

| 目标 | oracle | 可观测特征 probe | est_norm | random |
|---|---|---|---|---|
| 平均可靠度 `mean_r`（N=820） | −0.0075 | −0.0022 | −0.0076 | −0.0117 |
| `frac r≥0.5` | −0.0177 | **+0.0102** | −0.0116 | −0.0079 |
| **`frac r≥0.7`** | **+0.0398** | **+0.0266** | +0.0000 | **−0.0280** |

（N=186 高细胞子集给出同方向结果：mean_r −0.0058；frac≥0.7 oracle +0.0457 / probe +0.0296 / random −0.0457）

**结论（这是本轮最重要的新知识）**：

1. **如果目标是"提高所有扰动的平均测量质量"→ 均匀分配最优**，连 oracle 都赢不了（负值）。
   "自适应分配"在这个目标下**没有价值**。
2. **如果目标是尾部型**（"让尽可能多的扰动被测到高可靠度"，接近发现型目标），
   则自适应分配有**真实 headroom（+0.04）**，且**约 2/3 可由在线可观测特征实现（+0.027）**，
   而随机分配会**变差**（−0.028）→ 说明这是真信号而非假象。
3. 在线特征的可预测性：留一扰动 R² ≈ 0.17，Spearman 0.21~0.24（弱但非零）；
   `half_split_r`（观测细胞两半一致性）是最有用的在线代理之一。

→ 审阅提出的目标**可以成立，但必须把终点改成尾部/发现型指标**，并且预期增益是**相对 3~4%** 量级，
不是数量级提升。

## 三、下一步方案（按审阅的五步，补上可执行规格与验收标准）

### 第 0 步（立刻可做，无需新算力）：口径修正
- 全部文档改为 **AUC 为主指标**；@600 仅作辅助；标注重叠的 mean/median。
- 删除/降级四条过度陈述（oracle、stage4 感知、stage3 外推、偏差归因）。
- 报告中显式标注：代理的参考核含测试真值几何 → **离线诊断**；代理增益不可迁移。

### 第 1 步：把多保真环境做可信（最高优先级工程）
规格（直接采纳审阅意见）：
- 每个扰动拆成 **measurement pool** 与 **hidden reference**（互不相交；对照组也拆两半）；
- 追加测量 = **揭示新细胞**（nested prefix），累计计费，禁止重复抽取同一细胞充数；
- 所有方法共享同一预设细胞顺序（减少比较噪声）；
- 术语统一：**细胞数量分配**（不说"深度"）；
- 容量现实：34.1% 扰动 <100 细胞 → 主实验限定在满足容量的子集并**显式声明偏向高产量扰动**，
  同时在全体上报告 censored 曲线；
- 第一版以细胞数计预算，之后再加"新扰动启动成本/批次成本/对照成本"。
- **验收**：给定 (pool, reference, 细胞顺序) 后，环境可复现地产生任意预算下的观测与成本账单。

### 第 2 步：用非 LLM 策略证明"动态决策值得学"
必须与**开发集选出的最佳固定策略**比较（不能只赢 Random）。基于新证据，终点要选对：
- 主终点建议：**固定总细胞预算下，达到 r≥τ 的扰动数**（τ 由预注册确定，如 0.7），
  次要终点：平均可靠度（预期均匀最优，作为对照）。
- 对照矩阵：固定浅测/固定深测/固定两阶段/不确定性驱动/效果量驱动/oracle（诊断上界）。
- **验收**：在 ≥5 个任务划分上，自适应策略在主终点稳定优于最佳固定策略（配对检验），
  否则**停止**该子问题、不要投入 planner。

### 第 3 步：确定主要科学目标 + 发现型指标
- 二选一（预注册）：(A) 固定细胞预算下提高未见扰动响应预测；
  (B) 固定细胞预算下发现更多对**预先指定通路**有真实响应的扰动。
- 若选 (B)：真实响应必须由 **hidden reference 细胞**定义，**不能**把 GO 注释同时当选样依据与成功标签。
- 只靠汇总 CSV 能算的：预测学习曲线、基于选择列表+注释的 GO 覆盖（仅作辅助覆盖指标）；
  DE 恢复/通路响应误差需要预测值或保存的模型 → 需要补存预测。

### 第 4 步：接入 planner，并检验它**真的用了反馈**
- 最小动作空间：{扩展新扰动 vs 追加已有扰动} × {给哪些候选分配多少细胞}。
- 对照：最佳非 LLM 自适应 / 同工具 prompt-only LLM / 训练后 LLM /
  **冻结初始计划不随反馈调整** / **打乱反馈对应关系**。
- **"真实反馈 > 打乱反馈"是关键证据**，用于区分"靠预训练知识挑基因"与"真从本次实验反馈学习"。
- 先例存在（BioDiscoveryAgent），贡献必须比"接上 LLM 选样"更具体。

### 第 5 步：把迁移提升为核心（不是可选）
- 最终至少要有**一个未见任务或生物背景**：K562 内部通路留出（早期）→ 人工子空间位移（机制）→
  真实跨细胞背景（结论级，需要 RPE1 数据；本机当前缺失，需先获取）。
- 不同随机种子只是重复实验，**不是**迁移任务。

# 第二轮更正（stage7：严格隔离 + 精确整数深度）

## 1. stage6c 的 oracle 确实错了 —— 已验证并撤回相关结论

`stage6c_fair_allocation.py:89` 的 `for name, kind in OBJ.items():` 中 `kind` 是 **lambda**，
`kind == 'mean_r'` **恒为假** → 三个目标全部落进 `else` 分支（都用了 r≥0.7 的边际排序）。
因此 stage6c 表格里"三个 oracle"实际是同一个（错配的）oracle，
**"平均质量目标下均匀分配最优（oracle 为负）"的结论作废**。

同时撤回两处措辞：
- 25/100 两档策略族的最优方案输给均匀分配 → 只能否定**这个受限策略族**，不能证明均匀分配全局最优；
- "在线特征实现了约 2/3 收益"→ 原数字既非纯留出、也不是预算曲线的 AUC，且 `+0.0266` 是
  **2.66 个百分点**，不是相对 2.66%。

## 2. stage7：重做的可信评估（本轮新证据）

修复了四点：**① 去掉插值与累计最大值修正**（r(d) 在 **每个整数深度**用固定共享细胞顺序精确测量）；
**② 严格开发/测试隔离**（probe 只在 574 个 dev 扰动上拟合，分配与评分只在 246 个 test 扰动上）；
**③ 真实整数细胞与严格计费**；**④ 3 个独立参考划分**并报告跨划分标准差。
人群限制显式报告：pool≥100 的扰动占 39.9%（820/2057）。

测试池（N=246）上的预算曲线 AUC（budget 25→90 细胞/扰动）：

| 目标 | uniform | oracle | probe(dev拟合) | est_norm | half_split_r | random |
|---|---|---|---|---|---|---|
| mean_r | 0.4193 | **+0.0077** | −0.0078 | −0.0102 | −0.0110 | −0.0166 |
| frac r≥0.5 | 0.4174 | **+0.0219** | −0.0059 | −0.0180 | −0.0190 | −0.0282 |
| frac r≥0.7 | 0.2473 | +0.0216 | **+0.0206** | +0.0192 | +0.0176 | −0.0132 |

跨参考划分 std：0.001–0.009（probe 在 frac≥0.7 上 +0.0206 ± 0.005）。

**修正后的结论**：
1. **true oracle 在三个目标上都有正收益**（+0.008 ~ +0.022）→ 决策空间**确实存在**，
   不是"均匀分配全局最优"。
2. **但可部署规则的表现依赖目标**：mean_r 与 frac r≥0.5 上，所有在线规则仍**输给均匀分配**
   （−0.006 ~ −0.019），说明现有在线特征不足以捕捉那部分 headroom；
   只有 **frac r≥0.7 这类尾部目标**上，probe 能拿到 oracle 的 ~95%（+0.0206 vs +0.0216）。
3. `random` 在所有目标上一致为负 → 上述尾部收益是**真信号**。
4. **不把 τ=0.7 当作预注册终点**：它是本轮已看过的探索结果，必须在**未使用的新测试任务**上验证。
